# gis_42p6153_m5p5633_world

Gazebo (gz-sim) world generated by `navmap_tools`' `navmap_gis_tool` from
real-world GIS data:

* Center: 42.615323, -5.563265
* Size: 10.0 m x 10.0 m
* Elevation source: Copernicus DEM GLO-30 (~30 m, public AWS Open Data, no API key)
* Imagery source: PNOA (IGN Spain), 0.25 m/px

Attribution: contains modified Copernicus DEM data -- see
https://spacedata.copernicus.eu/ for its terms. Contains PNOA orthoimagery (c) Instituto Geografico Nacional de Espana, CC BY 4.0.

## Load directly into Gazebo (without ROS)

```bash
export GZ_SIM_RESOURCE_PATH=`pwd`/models:`pwd`/worlds
gz sim worlds/gis_42p6153_m5p5633.world
```

## ROS launch (standalone, no robot)

```bash
colcon build --symlink-install --packages-select gis_42p6153_m5p5633_world
source install/setup.bash
ros2 launch gis_42p6153_m5p5633_world gis_42p6153_m5p5633.launch.py
```

## NavMap

If generated with `--navmap`, `maps/gis_42p6153_m5p5633.pcd` and `maps/gis_42p6153_m5p5633.navmap`
sit alongside this world and share the exact same local-ENU origin (this
world's GPS center), so they line up with the terrain above even though they
may have been produced in a separate `navmap_gis_tool` run. Publish it for
RViz2 with:

```bash
ros2 run navmap_tools navmap_publisher --input maps/gis_42p6153_m5p5633.navmap
```
